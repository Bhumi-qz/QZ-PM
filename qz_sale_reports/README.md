# QZ Sales Reports

QZ Sales Reports is a module that adds custom Sales Proposal and AMC Agreement reports to Sales
Orders/Quotations. It adds extra proposal and AMC fields, branded PDF layouts, customer approval/signature support, and
uses the existing Sales Order.

It also supports:

- Custom Sales Proposal PDF
- Separate AMC Agreement PDF
- Customer signature/portal approval
- Automatic proposal/AMC attachments in quotation emails
- Existing standard quotation data remains unchanged.
